## 判定与根因

**验收目标 ≤ 0.05mm：未完全达成（典型 0.06mm，最大 0.14mm）**，差距在一个测量不确定度量级内。

根因链：
1. **标定拟合残差 0.83px ≈ 0.15mm** —— 这是当前精度天花板（板子轻微倾斜 + 打印纸面不平 + 点质心噪声）
2. **镜头径向畸变** —— 九点仿射是线性模型，补偿不了边缘畸变（换位后偏差从 +0.04 变 +0.10）
3. **打印纸材质** —— 纸面弯曲、点边缘洇墨

## 达到 ≤0.05mm 的提升路径（按性价比排序）

1. **标定板硬质化**：亚克力板打印/雕刻点阵，或贴在玻璃上 → 消除平面度误差
2. **拍摄正对**：手机垂直俯拍（当前有轻微倾斜）→ 残差可望降到 0.3px 以下
3. **限制测量区**：定义视场中央 60% 为有效测量区（工业惯例——夹具保证工位一致）
4. **二次标定**：拟合多项式畸变模型（≥15 点网格）补偿镜头畸变

## 结论

以手机相机 + 打印标定板的低成本方案，达到 **0.1mm 级精度**（典型 0.06mm）。
0.05mm 目标需要上述升级中的至少 1–2 项。
