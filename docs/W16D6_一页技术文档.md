# VisionInspect 技术文档（一页版）

## 1. 系统概述

机器视觉质检上位机：**相机 → 定位 → 测量 → 判定 → PLC** 闭环。替代人工卡尺测量 + 目检，单次测量节拍 21ms。

## 2. 数据流与架构

```
┌──────────┐   BlockingCollection   ┌──────────────┐   InspectResult   ┌─────────────────┐
│ 采集线程  │ ────（最新帧队列）────→ │  处理线程     │ ────────────────→ │ ① UI 画框画线    │
│ UVC/工业  │      丢旧帧·Dispose    │ 匹配→测量→判定│  {OK/NG,mm,坐标}  │ ② Modbus 写PLC   │
│ 相机     │                        │              │                   │ ③ 日志 + 历史    │
└──────────┘                        └──────────────┘                   └─────────────────┘
```

| 层 | 项目 | 职责 | 换硬件影响 |
|---|---|---|---|
| UI | VisionInspect.App | 画面/叠加/参数面板/历史 | 无 |
| 业务 | VisionInspect.Business | 处理线程、判定、统计、配置、日志 | 无 |
| 算法 | VisionInspect.Algorithm | 形状匹配、卡尺、九点标定 | 无 |
| 硬件 | VisionInspect.Hardware | 相机采集、Modbus、管线 | **仅此层** |

## 3. 算法流程图

```
图像 → 形状匹配（ignore_local_polarity 抗反光, 0.35x 降采样）
        │ 命中: 中心坐标 + 角度 + 尺度
        ├─→ 外径测量：3 弦卡尺（0°/60°/120°）→ 取最接近期望直径者
        │      边缘选点：排除圆心区（|s|<0.5R）防纹理干扰 → ±R 最近边缘对
        ├─→ 间距测量：中心区首尾边缘对（正交双方向取较小）
        └─→ 判定：|mm − 标称| ≤ 公差 → OK/NG
              └─→ mm 换算：九点标定仿射（端点变换取距，吸收各向异性）
```

**关键决策**：① 测量用卡尺不用 YOLO（检测框抖动 ±px，测尺寸需亚像素稳定）② ignore_local_polarity（金属反光翻转边缘极性）③ 九点标定（印刷板+仿射，卡尺溯源）④ 端点变换取距（优于单纯 px×比例）

## 5. 部署与运行

```
构建:  dotnet build VisionInspect.sln
运行:  src\VisionInspect.App\bin\Debug\net48\VisionInspect.exe
PLC:   python tools\virtual_plc.py        # Modbus TCP 1502
上手:  开始预览 → 拖框选目标 → 训练模板 → 实时测量
```

依赖：Windows + .NET 4.8 + HALCON 26.05（license）+ Python(pymodbus) + DroidCam/工业相机。
配置（模板/对比度/角度/标定/公差/Modbus）自动持久化于 `config.json`，异常全部落 `logs\`，断线自动重连。

## 6. 已知限制

精度天花板 ~0.05–0.1mm（打印标定板+手机镜头；升级路径：硬质标定板/垂直正拍/畸变标定）；
YOLO 缺陷检测未实现（"良好"档加分项，需缺陷样本集）；当前相机为手机 UVC（换海康 MVS 仅需实现 `IFrameSource`）；PLC 为虚拟从站（接真 PLC 只改 IP）。
