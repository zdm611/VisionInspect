# W14-D1 卡尺三要素笔记

卡尺（Caliper）= **1D 边缘测量**：沿一条线取灰度剖面，找灰度跳变点（边缘），输出边缘坐标。
Halcon 对应算子：`gen_measure_rectangle2`（定义测量 ROI）→ `measure_pos`（找边缘点）。

## 要素一：ROI 方向（Phi / Length1 / Length2）

`gen_measure_rectangle2(Row, Col, Phi, Length1, Length2, …)`：

| 参数 | 含义 | 对测量的影响 |
|---|---|---|
| **Phi** | 矩形长轴的方向角 | **测量沿长轴方向取剖面**——Phi 决定"从哪边扫到哪边"。Phi 转 90° 就是换一条测量线 |
| **Length1** | 长半轴 | 必须**跨过要测的两个边缘**（太短只切到一边，太长引入无关边缘） |
| **Length2** | 短半轴 | 沿短轴做灰度平均降噪。窄=定位准但怕噪，宽=平滑但边缘被抹钝 |

要点：剖面方向 = 长轴方向；短轴是"平均降噪带宽"。测直径就把 Phi 对准直径方向、Length1 取半径稍多。

## 要素二：边缘极性（Select：positive / negative / all）

灰度沿剖面方向的跳变分两种：

- **positive（正极性）**：暗 → 亮（灰度上升）
- **negative（负极性）**：亮 → 暗（灰度下降）
- **all**：两种都要

**⚠️ 极性反了会怎样（验收答案）**：

1. **直接丢点**：实际边缘是亮→暗（negative），却选了 positive → `measure_pos` 返回**空**，该边缘检不到，测量失败（少一个点）。
2. **错检假点**：阈值内的噪声跳变如果极性"恰好对上"，会被当成边缘顶替 → 测到错误位置，直径算错。
3. **单极性测不了直径**：以本项目硬币为例（**暗硬币、亮纸背景**）：
   - 沿剖面从左往右：左边缘是 亮→暗 = **negative**；右边缘是 暗→亮 = **positive**
   - 选 negative 只得左点、选 positive 只得右点——**直径要两个点，必须用 `all`**（或分两次单极性测量再配对）。

一句话：极性决定"认哪种跳变"，反了 = 该找的找不到、不该找的可能顶上。

## 要素三：阈值（Threshold + Sigma）

| 参数 | 含义 | 调节后果 |
|---|---|---|
| **Threshold** | 边缘最小灰度幅值（0–255） | 太高：软边缘/弱边缘漏检；太低：噪声、划痕、纹理被当成边缘（点数爆炸） |
| **Sigma** | 剖面高斯平滑系数 | 大→抗噪强但边缘定位变钝；小→定位准但怕噪 |

经验值起点：Threshold ≈ 20–40，Sigma ≈ 1.0，再按图像微调。

## 本项目（硬币测直径）的配置决定

- **Phi** = 匹配角度（沿模型长轴穿圆心的弦），Length1 = 半径 × 1.2（跨过两边）
- **极性 = all**（暗硬币亮背景，两边极性相反，见上）
- **Threshold = 30，Sigma = 1.0，Length2 = 6px**
- 取剖面**首尾两个最外侧边缘** = 圆的外径两端点（内部纹理边缘在中间，忽略）
- 已知参照：一元硬币直径 **25mm**（W15 九点标定后换算 px→mm 用）
