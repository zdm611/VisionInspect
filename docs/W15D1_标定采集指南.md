# W15-D1 九点标定采集指南

## 标定板

文件：`docs/W15D1_标定板_A4.pdf`（300 DPI 精确几何）

| 参数 | 值 |
|---|---|
| 点阵 | 3×3 圆点，直径 5mm |
| 点距 | **30.00 mm**（设计值） |
| 锚点 | 左上角点加大（8mm）——用于识别方向，对应网格 (0,0) |
| 比例尺 | 底部 60mm 校验条 |

## 打印（关键！）

1. A4 纸打印，**打印设置选「实际大小 / 100%」**，关掉"适应页面/缩放到纸张"
2. 打印后**用游标卡尺量相邻两点中心距**，应为 30.00mm
   - 允许误差 ±0.2mm；把**实测值**记下来（D2 拟合时代入实测值，抵消打印缩放误差）
   - 若偏差 > 0.5mm：检查打印设置重打，或量多点取均值继续
3. 把板子**平整**贴在硬纸板上（防弯折——弯了点距就变了）

## 采集 9 张标定图

相机固定（手机支架不动），标定板**平放**在视野里（尽量与手机像面平行 = 无畸变的关键）：

| 图号 | 板子位置（覆盖全视场） |
|---|---|
| calib_01 | 视野正中央 |
| calib_02 | 左上 |
| calib_03 | 右上 |
| calib_04 | 左下 |
| calib_05 | 右下 |
| calib_06 | 左中 |
| calib_07 | 右中 |
| calib_08 | 上中 |
| calib_09 | 下中 |

每张要求（验收标准「点清晰、无畸变」）：
- **9 个点完整可见**、不被遮挡
- **对焦清晰**（点边缘锐利，手机点按屏幕对焦到板面）
- 板子**放平**（别倾斜——倾斜会让圆点变椭圆 = 畸变）
- 光线均匀，避免反光盖住黑点

命名：`samples\calib\calib_01.png` … `calib_09.png`

## 无法打印时的替代

用直尺+笔在白纸上画 3×3 点阵（点距用卡尺/直尺量准，记录实测值），或用 9 个相同的小圆片（如螺母/垫圈）摆在画好格子的纸上——几何原理相同。

## 之后（D2 自动完成）

标定模块会：识别 9 个点的像素坐标 → 与 30mm 网格坐标配对 → 最小二乘拟合仿射变换 → 输出 px/mm 与变换矩阵 → 存入配置。
