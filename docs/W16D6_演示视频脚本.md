# 3 分钟演示视频脚本 —— VisionInspect

> 拍摄前提：手机相机固定在支架上俯拍桌面，硬币为被测件，虚拟 PLC 控制台开着。

## 0:30–1:30 演示（核心 60 秒）

| 时间 | 画面 | 旁白/字幕 | 操作 |
|---|---|---|---|
| 0:30 | App 界面空画面 | 「上位机启动，点开始预览」 | 点「开始预览」 |
| 0:40 | 实时画面 + 拖框画面上的硬币 | 「鼠标框选目标，一键训练模板」 | 拖 ROI → 点「训练模板」 |
| 0:55 | 绿框+青线+橙线实时跟硬币，状态栏跳动 | 「匹配框、外径测量线、间距测量线实时跟踪——外径 25.0 毫米，判定 OK」 | 挪动硬币展示跟踪 |
| 1:10 | 特写：状态栏「外径 25.xx mm [OK]」+ 历史列表滚动 | 「测量值实时换算毫米，公差判定 OK/NG，历史列表全程留痕」 | — |
| 1:20 | 特写：虚拟 PLC 控制台刷出「判定=OK 测量=25.xx mm」 | 「判定结果实时写入 PLC ——生产线上，这行字就是剔除气缸的触发信号」 | 把公差改成 0.05 → PLC 日志变 NG |

**演示小抄**：放件 → 预览 → 框选 → 训练 →（挪动硬币）→ 改公差看 OK/NG 翻转 → 指 PLC 控制台

## 1:30–2:30 讲方案（为什么这样做）

| 画面 | 旁白/字幕 |
|---|---|
| 架构图（四层 + 数据流） | 「四层架构：采集→队列→处理线程→结果，换相机只动硬件层」 |
| 九点标定板照片 + px/mm 公式 | 「为什么九点标定？像素不是毫米——用一块打印标定板建立换算，9 个点拟合仿射，顺带吸收镜头倾斜」 |
| 对比图：YOLO 检测框抖动 vs 卡尺边缘线 | 「为什么测量不用深度学习？检测框抖动 ±几个像素，而测尺寸要亚像素级稳定——1D 卡尺找边缘才是计量学正解。YOLO 留给缺陷分类，各干各的」 |
| 数据表特写：CT 21ms / std 0.042px / 2000 次无泄漏 | 「实测：单次 21 毫秒，重复性 0.04 像素，两千次长跑内存零增长」 |

## 2:30–3:00 踩过的坑（选 2 个）

| 画面 | 旁白/字幕 |
|---|---|
| 匹配框乱跳的录屏（0.09 分）→ 修复后（0.76 分） | 「坑一：金属硬币反光会翻转边缘极性，匹配得分只有 0.09——换 ignore_local_polarity 配置后升到 0.76。**反光金属件必须抗极性**」 |
| 误差表：+0.30mm → 卡尺量标定板 → +0.06mm | 「坑二：打印的标定板缩水到 90%没人发现，误差 0.3 毫米——用卡尺回头量标定板才破案。**测量系统的每个数字都要有溯源链**」 |
| 收尾空镜 + 系统全貌 | 「小而完整，胜过大而残缺。谢谢观看」 |
