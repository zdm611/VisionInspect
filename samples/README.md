# samples — 测试图说明

放在这里：**1 张模板图 + 20 张测试图**，用手机拍摄后拷入。

## 素材

- 对象：**同一枚一元硬币**（25mm，正好衔接 W14 测量参照）
- 光照：台灯固定，避免反光斑
- 机位：手机固定不动（支架/摞书），镜头俯拍桌面

## 文件

| 文件名 | 内容 |
|---|---|
| `template.png` | 硬币居中、对焦清晰的一张（模板） |
| `test_01.png` … `test_20.png` | 同一硬币，每张换位置（中心/四角/边缘）+ 平面内转 10°～30° |

要求：
- 硬币直径约占画面高度 **1/3～1/2**
- 深色背景放亮硬币 / 亮背景放暗硬币，边缘清楚
- 每张硬币完整在画面内、无遮挡

## 验收

```
src\VisionInspect.MatchTest\bin\Debug\net48\VisionInspect.MatchTest.exe samples\template.png samples
```

输出 `结果：20/20 找到` 即通过。
